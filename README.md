# biuroadmin.online

Oficjalna strona internetowa **Biura Rachunkowego Jarosław Konik** ([biuroadmin.online](https://biuroadmin.online)).

## Usługi
* Księgowość i rachunkowość (CIT, PIT, pełna księgowość)
* Kadry i płace
* Rozliczenia ZUS i e-ZUS
* Wdrożenie i obsługa KSeF (Krajowy System e-Faktur)

## Strefa Klienta
Panel klienta dostępny pod adresem: [portal.biuroadmin.online](https://portal.biuroadmin.online)

## Hosting
Strona hostowana bezpośrednio na GitHub Pages z pełnym wsparciem SSL/TLS (HTTPS).
